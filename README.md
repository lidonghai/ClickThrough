# ClickThrough
This AutoHotkey (v2) script allows you to quickly activate and bring forward the window directly beneath your mouse cursor without sending a mouse click.

Key Features:
* Hotkey Trigger: Press Ctrl + Shift + Left Click (^+LButton) anywhere on the screen.
* Z-Order Window Traversal: It inspects all visible overlapping windows under your cursor in top-to-bottom order (Z-Order) and selects the next one down.
* Click-Free Activation: Brings the underlying window to the front without clicking inside it, preventing accidental button triggers or text selection.
* DPI & Multi-Monitor Aware: Handles High DPI scaling and absolute screen coordinates accurately to avoid position offsets.
* Smart Filtering: Automatically ignores invisible, tiny, and system desktop/taskbar elements.
* Visual Feedback: Shows a temporary ToolTip displaying the newly activated window's title.
